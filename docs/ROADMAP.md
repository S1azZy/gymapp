# Roadmap

## MVP

- secure auth with email/password
- user accounts + admin role
- shared exercise catalog
- exercise classification
- exercise images and tags
- workout templates
- real workout sessions
- draft workouts
- plan vs fact behavior
- sets with reps/weights
- wellbeing score 1..5
- rest timer
- autofill last used weight
- calendar history
- best set / estimated 1RM statistics
- admin area
- RU/EN localization
- Docker + CI + security scans

## Version 1.1

- Google login
- Apple login
- improved stats module
- user-created exercise extensions on top of shared catalog
- more advanced filtering/search

## Version 1.2

- AI progress analysis
- AI advice summaries
- text-to-workout parsing

## Version 1.3

- Telegram bot ingestion
- reusable ingestion pipeline shared with web input

## Version 1.4

- Hotwire Native wrappers for iOS and Android if web MVP proves strong
